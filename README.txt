# AI-Powered Job Portal

An ASP.NET MVC web application built with C# that connects job seekers and employers and uses AI to generate personalized feedback for job applicants.

## Overview

The AI-Powered Job Portal aims to make recruitment easier for employers and help job seekers improve their applications. The application follows the **Model–View–Controller (MVC)** architecture, separating data and business logic, user interfaces, and request handling.

## Main Features

- Browse available job opportunities and view job details.
- Submit applications for suitable positions.
- Allow employers to post and manage job listings.
- Allow employers to review job applications.
- Generate personalized AI feedback for candidates based on their application information.
